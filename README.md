## 기능

**탭**

- **D-MAX** — [전체 | 딜러 | 탱커] 세그먼트 + 속성 칩 하위 메뉴. 전체 = 티어표(pogomate 기준: 공격 × 맥스무브 위력 × 자속, 1위 대비 %, 행을 누르면 선정 근거·카운터), 딜러 = 보스 속성 상대 맥스 어태커, 탱커 = 체력 × 방어 ÷ 받는 배율(EHP). 상단 "⚔️ 이번 주 보스" 아코디언 + 딜러 2·탱커 1 파티 카드
- **PvE** — 일반(구하기 쉬운 개체) / 전체(hawaii 성능표 + 자체 계산) 토글, 오른쪽 🧮 **솔플 레이드 계산기**(보스 검색 → 티어 자동 판정 → 부활 운용 시뮬레이션 → 가능 여부·필요 개체·딜 총량)
- **PvP** — 리틀·슈퍼·하이퍼·마스터, PvPoke 점수·추천 기술, 오른쪽 🃏 **PvP 덱 짜기**(리그 메타 추천 덱 3종 + 상대 슬롯 기반 커스텀 덱·카운터, 이유 자동 설명)
- **활용처**는 🔍 검색 패널 안에 — 비워 두면 여러 순위표에서 상위권인 순위, 검색 후보마다 "활용 N곳" 뱃지 (v2.16.0, 탭 제거)

**도감 (탭 줄 📕)**

- 넘버링순 전 종 목록, 이름·번호 검색, 1~9세대 점프, 1↔2열 토글, 미출시 [미구현] 태그
- 상세 팝업: 타입 → 이름 → CP(레이드 보상·야생 스폰, 날씨부스트 구분) → 내 개체 CP 계산기 → 능력치 육각형·기술 → 상성 → 활용처 → 진화(메가 폼 포함, 메가X/Y 비교표)

**🌱 플래너 모드 (헤더 배지로 전환, v2.15.0)**

- 도감이 "뭐가 세나"라면 플래너는 "내 개체를 어떻게 키우나". 탭 줄이 [홈 | 내 포켓몬]으로 바뀌고 주소는 `#/plan/*`
- **내 포켓몬** — 실제 개체를 종·폼·섀도우·레벨·개체값·기술·상태·메모 단위로 계정에 저장(같은 종 여러 마리), CP 자동 계산·CP로 레벨 추정, 같은 종 두 개체 비교(만렙 CP·리그 도달 CP). 상세 팝업 ➕로 바로 저장

**공통**

- 🔐 Google 로그인(관리자 승인제) · 즐겨찾기 ★를 계정에 저장 → 어느 기기에서든 같은 도감. 첫 로그인 때 약관·개인정보처리방침 동의(만 14세 이상), 계정 삭제 셀프서비스, 통계(GA) 동의 배너 (v2.18.0)
- 📅 월 일정표 달력(LeekDuck + 한국 공식 발표) + 분류 칩·기간 막대 타임라인, 전역 검색, 트레이너 코드(승인자 전용), 패치노트
- PWA 설치·오프라인 열람, 다크 모드, 첫 화면 로딩 표시, 그림 스켈레톤, 웹폰트(Montserrat + Pretendard), 프레임워크·의존성 없는 바닐라 JS

## 빠른 시작

Python 3.10+와 curl만 있으면 됩니다 (pip 설치·가상환경 불필요).

```bash
bash scripts/build.sh    # 원본 다운로드 + 전체 빌드
open dist/index.html     # 정적 파일이라 서버 없이 열림
```

화면만 고쳤다면 `python3 backend/build.py`로 충분합니다. 자세한 재빌드 범위는 [개발 문서](docs/DEVELOPMENT.md#8-저장소-구조와-로컬-실행) 참고.
