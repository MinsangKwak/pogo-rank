# POGO SEARCH — 편하게 검색하세요

포켓몬고 랭킹(D-MAX · PvE · PvP · 활용처), 도감, 월 일정표, 솔플 레이드 계산기를 한 페이지에서 보는 **포켓몬고 응애 친구들을 위한 정적 사이트**입니다.
서버 없이 GitHub Actions가 매일 데이터를 다시 받아 빌드·배포하며, 홈 화면에 설치(PWA)해 앱처럼 쓸 수 있습니다.

## 기능

**탭**

- **D-MAX** — 티어표(pogomate 기준: 공격 × 맥스무브 위력 × 자속, 1위 대비 %), 행을 누르면 선정 근거·카운터, 상단 "⚔️ 이번 주 보스" 아코디언
- **PvE** — 일반(구하기 쉬운 개체) / 전체(hawaii 성능표 + 자체 계산) 토글
- **PvP** — 리틀·슈퍼·하이퍼·마스터, PvPoke 점수·추천 기술
- **활용처** — 한 포켓몬이 어디에서 상위권인지 요약
- **IF** (실험 기능) — **솔플 레이드 계산기**(보스 검색 → 티어 자동 판정 → 부활 운용 시뮬레이션 → 가능 여부·필요 개체·딜 총량) / **PvP 덱 짜기**(리그 메타 추천 덱 3종 + 상대 슬롯 기반 커스텀 덱·카운터, 이유 자동 설명)

**도감 (☰ → 📕)**

- 넘버링순 전 종 목록, 이름·번호 검색, 1~9세대 점프, 1↔2열 토글, 미출시 [미구현] 태그
- 상세 팝업: 타입 → 이름 → CP(레이드 보상·야생 스폰, 날씨부스트 구분) → 내 개체 CP 계산기 → 능력치 육각형·기술 → 상성 → 활용처 → 진화(메가 폼 포함, 메가X/Y 비교표)

**공통**

- 🔐 Google 로그인(관리자 승인제) · 즐겨찾기 ★를 계정에 저장 → 어느 기기에서든 같은 도감
- 📅 월 일정표 달력(LeekDuck + 한국 공식 발표), 전역 검색, 트레이너 코드(승인자 전용), 패치노트
- PWA 설치·오프라인 열람, 다크 모드, 첫 화면 로딩 표시, 프레임워크·의존성 없는 바닐라 JS

## 빠른 시작

Python 3.10+와 curl만 있으면 됩니다 (pip 설치·가상환경 불필요).

```bash
bash scripts/build.sh    # 원본 다운로드 + 전체 빌드
open dist/index.html     # 정적 파일이라 서버 없이 열림
```

화면만 고쳤다면 `python3 backend/build.py`로 충분합니다. 자세한 재빌드 범위는 [개발 문서](docs/DEVELOPMENT.md#8-저장소-구조와-로컬-실행) 참고.
