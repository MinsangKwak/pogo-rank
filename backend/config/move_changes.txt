# 시즌 기술 변경 목록 — 이 파일만 손으로 관리한다
#
# 출처: 포켓몬 GO 공식 공지 "GO 배틀리그: 황혼의 발자취" (pokemongo.com, 2026-09-04 확인)
#       교차 확인: pokemongohub.net 같은 시즌 기술 변경 정리 글
# ★ 공지의 위력 수치는 트레이너 배틀(PvP) 값이다.
#   포켓몬 GO 게임마스터는 같은 기술이라도 레이드·체육관용 위력(moveSettings.power)과
#   트레이너 배틀용 위력(combatMove.power)을 따로 갖고 있고, 시즌 조정은 보통 후자만 건드린다.
#   실제로 이번 공지의 '이전 값'은 전부 combatMove 쪽과 일치한다
#   (예: 아이언헤드 공지 70 → 레이드용은 60, 배틀용이 70).
#   레이드·체육관까지 바뀌는 경우에는 공지가 그렇게 따로 밝힌다 (이번엔 사이코부스트 하나).
#
# 새 시즌이 오면 이 파일 내용을 통째로 갈아끼운다. 지난 시즌 내용을 남겨 두지 않는다
# (사이트에는 "다가오는/방금 적용된 변경" 하나만 보이면 되기 때문).
#
# '#' 뒤는 주석. 빈 줄은 무시한다.
#
# ── 형식 ──────────────────────────────────────────────────────────────────
# SEASON <시즌 이름>
# DATE   <적용일 YYYY-MM-DD>      이 날짜가 지나면 사이트의 "예고" 표시가 저절로 사라진다
#
# M <up|down> <기술ID> <이전위력> <이후위력> [| 비고]
#     위력이 바뀐 기술. up/down 은 "위력" 기준으로만 판단한다.
#     에너지가 같이 움직였으면 비고에 적는다 (위력은 올랐는데 에너지 비용도 오른 경우가 많다).
# E <기술ID> [| 비고]
#     위력은 그대로고 에너지만 바뀐 기술.
# N <포켓몬ID> <폼|-> <기술ID>
#     새로 배우게 되는 기술. 폼이 없으면 '-' (기본 폼).
#
# 기술ID·포켓몬ID는 게임마스터 표기를 그대로 쓴다. 빠른 기술의 _FAST 접미사는 붙여도 되고
# 빼도 된다 (빌더가 알아서 맞춘다). 한글 기술명·포켓몬명은 빌더가 자동으로 붙인다.
# ──────────────────────────────────────────────────────────────────────────
