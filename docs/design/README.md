# 디자인 구현과 검증

[프로젝트 소개](../../README.md) · [개발 가이드](../DEVELOPMENT.md) · [작업 지침](../../.claude/CLAUDE.md) · [맥스 배틀 배너](max-battle-banners-2026-10.md)

**정보의 위계는 유지하고, 공통 스타일과 화면별 배치를 분리합니다.** 밝은·어두운 테마와 모바일·PC에서 같은 정보를 읽을 수 있도록 설계합니다. 사용자 흐름과 피드백은 [서비스 기획](../portfolio/02-product.md)에서 설명합니다.

## 스타일 구조

v6(2026-10-17)부터 현재 체계는 `web/src/styles/pixel/`의 '픽셀 필드 시스템'입니다. `styles.ts` 맨 뒤에 실려 옛 이름 토큰을 새 값으로 다시 매기고, 이전 `cinema/*`·`brand.css`는 화면이 옮겨 가는 대로 걷어 냅니다. 옛 규칙을 덮을 때는 `html body #root` 접두사 하나만 씁니다.

| 파일 | 책임 |
| --- | --- |
| `web/src/styles/pixel/tokens.css` | 밤·낮 테마의 시맨틱 토큰. 옛 이름(`--bg`·`--surface`·`--brand`)도 여기서 다시 매김 |
| `fonts.css` | 글꼴 로딩 |
| `parts.css` | 픽셀 스킨 조각 — 판, 버튼, 배지, 칩, 탭, 입력, 표, 지표, 카드 |
| `shell.css` | 머리줄, 메뉴 레일, 하단 바로가기, 전체 메뉴 시트, 화면 머리 |
| `home.css` | 홈 히어로·주간 브리핑·보스 목록 배치 |
| `ranks.css` | 도감·D-MAX·PvE·PvP 배치 |
| `tools.css` | D-MAX 덱·솔플 계산기·PvP 덱·개체값 순위 배치 |
| `news.css` | 게임 업데이트·기술 변경·일정·레이드·알 부화 배치 |
| `info.css` | 내 포켓몬·검색식·설정·패치 노트·약관 배치 |
| `modal.css` | 상세·검색·로그인 안내·동의·통계 설정 팝업과 바닥 시트 |
| `admin.css` | 관리자 캠프 전용 셸과 화면 |

구성요소는 `PxParts`(판·버튼·배지·입력·지표·표), `PxDialog`(팝업 네 조각), `ToolBits`·`NewsBits`(도구·소식 조각), `SwapDialog`(포켓몬 교체), `Toast`(짧은 알림)입니다. 새 모양을 추가하기 전에 이 조각을 먼저 확인합니다.

색상과 모서리 반경은 토큰으로 관리합니다. 이미지 위 텍스트에는 `--plate` 팔레트를 적용해 배경과의 명암을 확보합니다. 일반 카드의 본문색을 그대로 사용하지 않습니다.

라이트 테마에서는 이미지를 밝게 덮고 진한 글자를 사용합니다. 항상 어두운 팝업·서랍 가림막에는 `--night` 팔레트를 사용합니다. 공통 모양을 추가할 때는 기존 선택자와 구성요소를 먼저 확인합니다.

## 화면 설계 기준

- 제목·설명·주요 행동의 위계를 먼저 정합니다.
- 터치 영역은 최소 44px로 유지하고 모바일에서도 주요 기능을 찾을 수 있게 합니다.
- 긴 한국어·영어 문구, 빈 데이터, 여러 줄 제목을 함께 확인합니다.
- 선택·포커스 상태는 색만이 아니라 테두리와 형태로도 구분합니다.
- 배너는 텍스트 영역과 피사체 위치를 분리하고 화면 폭에 따른 잘림을 확인합니다.
- 기능·권한·계산 정책을 시각적 변경과 함께 임의로 바꾸지 않습니다.

## 검증

| 검사 | 확인하는 내용 |
| --- | --- |
| `web/src/test/designgrid.test.ts` | 토큰·격자·하드코딩 스타일 규칙 |
| `scripts/check_screens.mjs` | 렌더된 화면의 비정상 표시 값 |
| `scripts/check_contrast.mjs` | 텍스트가 배경에 묻히는 회귀 |
| Storybook | 공통 구성요소의 상태와 두 테마 |
| 브라우저 직접 확인 | 모바일·PC, 키보드, 모달, 스크롤, 이미지 잘림 |

명암비 회귀 검사는 전체 접근성 감사와 다릅니다. 테스트 통과만으로 스크린리더·키보드 접근성까지 검증했다고 적지 않습니다. Storybook 실행은 [이전 앱·도구 안내](../../frontend-v4/README.md)를 참고합니다.
