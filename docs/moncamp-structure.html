데이터와 로그인

데이터빌드 때 굽는 정적 JSON 묶음 — 서버 없음. 티어표·도감·일정·스프라이트 출처Game Master · pogomate(D-MAX) · hawaii(PvE) · PvPoke(PvP) · LeekDuck(일정) 로그인Google 계정 하나. 승인제 — 첫 로그인은 '승인 대기', 루트가 승인 계정에 저장★ 즐겨찾기 · 화면 테마 · 약관 동의 기록 (그것뿐입니다) 권한 갱신탭으로 돌아올 때 다시 읽음 (1분 간격). 못 읽으면 마지막 판정 유지 SDKFirebase 는 첫 그림 뒤에 받음 — 티어표만 보러 온 사람의 첫 화면을 늦추지 않게
📣 담아 둔 포켓몬 소식 — ★ 를 담으면 그 종의 커뮤니티 데이·스포트라이트·레이드 일정을 상세와 내 포켓몬 화면에서 챙겨 줍니다. ★ 를 담을 이유가 여기서 생깁니다.

검사는 버그를 다시 넣어 빨개지는지까지 봅니다. v4.2.x 에서 라우트 삭제·깃발 제거·권한 재확인·계정 삭제·계정 카드 다섯 갈래를 주입해 확인했습니다.
지금 없는 것 — 🎒 내 개체 기록(종·레벨·개체값·기술·메모)은 v3 에서도 스위치가 내려가 있고 v4 에 옮기지 않았습니다. 내 포켓몬 화면은 📣 소식 + ★ 목록입니다. 회원 분석 대시보드·광고도 없습니다.
이 그림은 코드와 운영 주소를 대조해 그렸습니다 — 화면 목록은 frontend-v4/src/routes.ts, 권한은 stores/auth.ts · lib/useLocked.ts · firestore.rules 기준입니다.
