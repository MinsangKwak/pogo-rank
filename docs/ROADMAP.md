# 로드맵과 v5 전환 결과

[프로젝트 소개](../README.md) · [개발 이력](HISTORY.md) · [개발 가이드](DEVELOPMENT.md) · [전환 기록](V5-CUTOVER.md)

**v5는 Next.js와 자체 인증 API로 전환한 단계입니다.** 이 문서는 초기 목표, 완료한 구현, 후속 확인이 필요한 항목을 구분합니다. 기준일은 2026-09-26입니다.

## 전환 배경

| 이전 문제 | 선택한 방향 |
| --- | --- |
| 해시 주소가 같은 HTML을 제공하여 포켓몬 상세 문서를 구분하기 어려움 | 경로별 정적 HTML과 메타데이터 생성 |
| 로그인·권한 규칙이 프런트엔드와 Firebase에 나뉨 | Google OAuth와 서버 인가로 계정 처리 통합 |
| 정적 화면과 사용자 데이터의 변경 주기가 다름 | Python 게임 데이터 빌드는 유지하고 계정 API를 분리 |
| 버전 정보가 여러 파일에 중복됨 | `content/version.json`을 원본으로 사용하고 일치 검사 |

## 초기 계획과 실제 구현의 차이

| 초기 계획 | 현재 상태 |
| --- | --- |
| 순위 화면 ISR | 게임 데이터를 생성한 뒤 배포 빌드로 반영하는 흐름 유지. 전체 ISR 완료로 표기하지 않음 |
| 모든 토큰을 숨기는 BFF | 리프레시 토큰은 HttpOnly 쿠키, 액세스 JWT는 브라우저 메모리에서 사용 |
| Firebase·v4 완전 제거 | `frontend-v4`의 데이터 추출·Storybook과 이전 복구 자원이 남아 있음 |
| 개체별 내 포켓몬 API | 사용하지 않는 `mons` 테이블은 만들지 않음 |

기존 [목표 구조 이미지](roadmap-target.png)는 당시 계획 자료입니다. 현재 구조는 [README](../README.md#구조)를 기준으로 합니다.

## 후속 확인 항목

| 항목 | 완료 판단 기준 |
| --- | --- |
| 이전 Firebase 자원 정리 | 복구 기간 종료, 현행 OAuth 클라이언트 의존성 확인, 필요한 백업 보관 |
| v4 도구 의존성 분리 | 데이터 추출과 Storybook을 대체한 뒤에도 CI·개발 미리보기 정상 |
| 현재 DB 복구 점검 | Neon 데이터의 백업 범위와 실제 복원 절차 확인. Firestore 백업과 구분 |
| 계산 정확도 보강 | 보스별 실측 사례와 오차 범위를 추가하고 가정·표시를 함께 갱신 |
| 접근성 검토 | 명암비 회귀 검사 외에 키보드·스크린리더·포커스 동작 검토 |

이 항목들은 개선·확인 대상이며 완료된 성과로 표시하지 않습니다. 구체적 일정은 정해진 뒤 기록합니다.

## 유지하는 호환성

`pogo_*` 저장 키와 값, GA 이벤트명, 저장소명, 공유 경로를 유지합니다. 해시 주소는 기존 경로로 연결하고, 이전 경로의 리디렉션을 검증합니다. Firestore 필드 변경은 데이터 이관으로 처리한 예외이며 일반 리팩터링에서 임의로 바꿀 수 있다는 의미는 아닙니다.

## 개발 방식

보안·데이터 변경은 실패 조건을 먼저 검증하고, 릴리스는 사용자에게 설명할 수 있는 단위로 묶습니다. 코드·문서·실제 운영 상태가 다른 경우에는 그 차이를 명시합니다.
