**코드로는 못 고치는 것 (주인 판단)**

- **저작권 심사 위험** — 포켓몬 스프라이트 · 이름과 배너의 포켓몬 그림(자체 제작 일러스트)은 권리자의 저작물이다. 비슷한 팬 사이트(도감 · 순위)들이 AdSense 를 쓰고 있어 흔히 통과하지만, Google 이 '저작권 보호 자료' 로 거절할 수 있다. 거절되면 이의 신청에 비공식 · 출처 고지 · 권리자 요청 시 삭제(약관 5항)를 적는다.
- **Vercel 플랜** — Hobby 는 광고를 금지한다(INFRA §8). 운영 프로젝트가 Pro 인지 대시보드에서 확인한다.
- **운영 반영이 한 번 필요하다** — 심사는 운영 주소(moncamp.kr)에 ads.txt(또는 확인용 메타 태그)가 있어야 시작된다. 지금 운영 보류 중이라, 심사를 시작하려면 보류를 풀거나 ads.txt 만 운영에 내는 방법을 주인이 정해야 한다.

## 3. 주인이 할 일 — 순서대로

1. **광고 시행일 정하기** — 오늘 + 7일 이상. 그 날을 알려 주시면 `ADS_FROM` 에 넣고 패치노트에 고지를 올립니다(고지가 시행일 7일 전보다 늦으면 검사가 막는다).
2. **AdSense 가입** — `https://adsense.google.com`, 개인 계정, 국가 한국, 결제 수취인은 실명. 사이트에 `moncamp.kr` 을 더한다.
3. **게시자 ID 알려 주기** — `ca-pub-` 로 시작하는 16자리. 비밀이 아니라 저장소에 둡니다.
4. **운영에 ads.txt 내는 방법 정하기** — 보류를 풀거나, ads.txt 만 운영에 내거나. 서면 심사를 신청한다(보통 1 ~ 4주).
5. **유럽 동의 창 켜기** — AdSense → 개인 정보 보호 및 메시지 → 유럽 규정 메시지.
6. **승인되면 광고 단위 셋 만들기** — 디스플레이 · 고정 크기 `왼쪽 160×600` · `오른쪽 160×600` · `바닥 320×50`. 슬롯 ID 셋을 알려 주세요.
7. **결제 정보** — 주소 확인 PIN 우편($10 도달 뒤), 세금 정보(개인 · 한국 거주 · W-8BEN), 외화 수취 계좌. 지급 기준 월 $100. 한국 거주 개인의 AdSense 수익은 종합소득세 신고 대상이다.
8. **Vercel 운영 프로젝트가 Pro 인지 확인.**

**본인 클릭 금지** — dev 에서 실제 광고를 보더라도 누르지 않는다(무효 클릭으로 계정 정지).

## 4. 승인 뒤 코드 (Claude 가 합니다)

| 자리 | 넣을 것 |
| --- | --- |
| `web/.env.production` | `NEXT_PUBLIC_ADS=live` · `NEXT_PUBLIC_ADSENSE_CLIENT=ca-pub-…` · 슬롯 ID 셋. 모두 공개 식별자(비밀 아님). dev 도 `dev-pipeline.yml` 에서 먼저 `live` 로 본다 |
| `web/src/lib/ads.ts` | `AdsMode` 에 `'live'` — 게시자 ID 가 없으면 `off` 로 읽는다 |
| `web/src/components/AdSlots.tsx` | `live` 면 상자 안에 `<ins class="adsbygoogle">`(고정 크기 · `data-ad-client` · `data-ad-slot`)를 두고 마운트 때 `push({})` 한 번. 스크립트(`pagead2.googlesyndication.com/pagead/js/adsbygoogle.js?client=…`)는 **자리가 보일 때만 동적으로 한 번** 심는다 — 로그인한 사람 · 통계를 끈 사람 · 광고 없는 화면에서는 Google 에 요청이 안 나간다. 심기 전에 `requestNonPersonalizedAds = 1` |
| `web/src/lib/legalMeta.ts` | `ADS_FROM` 에 시행일(3-1 에서 이미 넣음) |
| 검사 | `ads.test.ts` 에 `live` 판정 · 스크립트 한 번만 · 비개인 광고 줄. 운영 `.env.production` 의 `live` 는 `ADS_FROM` 이 있을 때만 허용 |

성능 · 정책: 자리 크기가 고정이라 광고가 늦게 와도 본문이 안 움직인다(CLS 0). 광고가 안 오면(차단기 · 미채움) 상자는 비어 있다. '광고' 표시는 그대로 두고, 클릭을 유도하는 글은 금지. GA4 와 AdSense 연결은 선택.

## 5. 운영 반영과 사후 확인

1. dev 에서 `live` 로 로그아웃 · 로그인, 넓은 화면 · 휴대폰, 라이트 · 다크, 통계 켜기 · 끄기를 본다(`scripts/check_screens.mjs` · `check_contrast.mjs` · Playwright).
2. 시행일이 지난 뒤 약관 · 방침 · 패치노트 · `.env.production` 을 한 판(v5.11.0 예정)으로 운영에 올린다 — **운영 보류가 풀린 뒤**.
3. 올린 뒤: AdSense '사이트' 에 ads.txt '승인됨', '정책 센터' 에 경고 없음, 광고 요청 수가 로그인 전 방문 수와 비슷한지(로그인한 사람에게 안 나가는지). 운영 `/privacy` · `/terms` 가 새 시행일을 보이는지.

## 6. 하지 않을 것

- 로그인한 사람 · 통계를 끈 사람에게 광고를 보이는 것 — `adsVisible` 한 곳에서만 판정한다.
- 자동광고(Auto ads) — 자리를 Google 이 정해 로그인 제외 · 광고 없는 화면 · 배치 규칙이 깨진다.
- 약관 개정(`ADS_FROM`) 없이 운영에 `placeholder` 나 `live` 를 켜는 것 — `adslegal.test.ts` 가 `.env.production` 의 `off` 를 지킨다.
- `public/ads.txt` 를 손으로 두는 것 — 경로가 겹친다(검사가 막는다).
