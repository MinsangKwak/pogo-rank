만들고 내보내는 길

게임 자료는 GitHub Actions 가 모아 계산하고, 화면은 그 산출물을 받아 정적으로 굽습니다.

원본→ GHPython 계산→ JSON · 이미지→ Next.js 빌드→ Pages
원본PokeMiners 게임마스터 · PvPoke · PokeAPI(한국어 이름) · ScrapedDuck/LeekDuck(일정) · 공식 한국 발표 데이터backend/ · scripts/build.sh — 원본 검증, 빠지면 정상본으로 대체하거나 멈춤 화면web/ Next.js — BUILD_TARGET=static → out/ APIserver/ Fastify → deploy-server.yml → Cloud Run 판 번호content/version.json 한 곳
dev→ PR→ main→ PR→ deploy→ moncamp.kr
dev 가지는 dev.moncamp.kr(Vercel)로, deploy 가지는 moncamp.kr(Pages)로 나갑니다. 새 디자인과 v5.10.x 는 아직 dev 에만 있습니다.

지키는 규칙

Pages 로 옮기며 프록시를 켜서 Cloudflare 영역 규칙이 다시 걸립니다.

자리규칙
요청 제한burst-guard — 같은 IP 10초 200회 넘으면 막음
캐시immutable-assets(/assets · /sprites · /sprites-anim 1년) · data-json(/data/*?v= 1년). /_next/static 1년은 Pages _headers
헤더security-headers + Pages _headers 보안 헤더 다섯
끈 것Email Obfuscation · Rocket Loader — Cloudflare 가 HTML 을 고쳐 써서 화면이 깨질 수 있어
API허용 Origin · 스키마 검사 · 분당 한도 · JWT 역할 검사 · IP 저장 안 함

되돌리기용으로만 남긴 것

평소엔 아무것도 받지 않습니다. 문제가 생기면 한 번에 되돌릴 수 있게 둡니다.
