# moncamp 디자인 시스템

**이 도면은 화면과 같은 CSS 를 쓴다.** 스토리북만 따로 스타일을 두면 도면과 화면이 갈라지고,
그 순간 도면은 믿을 수 없는 그림이 된다. `.storybook/preview.tsx` 가 `src/styles.ts` 한 줄을
싣는 이유다 — v3 스킨 24장과 v4 화면 CSS 7장이 앱과 **같은 차례로** 들어온다.

## 무엇이 어디 있나

| 층 | 자리 | 무엇 |
| --- | --- | --- |
| 값 | `frontend/styles/tokens.css` | 토큰 168개. **값은 여기 한 곳뿐이다** |
| 목록 | `src/ds/tokens.ts` | 이름과 쓰임새. 값은 안 적는다 |
| 조각 | `src/ds/*.tsx` | 버튼 · 칩 · 카드 · 표식 · 값 관문 |
| 규칙 | `src/styles/ds.css` | v3 에 짝이 없는 조각만 |
| 그물 | `src/test/dstokens.test.ts` | 목록과 값이 어긋나면 선다 |

## 세 가지 약속

### 1. 새 클래스를 함부로 만들지 않는다

버튼 · 칩 · 세그먼트 · 뱃지는 v3 CSS 가 이미 계약(클래스명 · 태그 · 중첩)을 들고 있고,
회귀 검사가 그 계약을 붙잡고 있다. `ds/` 의 조각은 그 클래스를 **그대로 내보낸다** —
같은 모양을 새 이름으로 다시 그리면 디자인이 두 벌이 되고 한쪽만 고쳐진다.

없던 것만 `ds.css` 에서 만든다: 배치(`.ds-stack` · `.ds-inline`) · 글자(`.ds-text`) ·
안내(`.ds-callout`) · 카드(`.ds-card`) 넷이다.

### 2. 격자 밖 값이 **안 들어가게** 만든다

지침으로 적어 두면 또 샌다 — v4.3.4 에 크기 474군데 · 간격 1,484군데가 격자 밖이었다.
그래서 타입으로 막는다.

- `<Stack gap>` · `<Inline gap>` 은 `none·xs·sm·md·lg·xl` 여섯 칸뿐이다 (4px 격자)
- `<Text size>` 는 `sub·body·lead` (Pretendard 12·14·16)
- `<Label size>` 는 `body·sec·title·hero` (Galmuri 14·22·28·42)

`<Label size="sub">` 는 **못 써진다.** Galmuri 12px 은 11·14 격자의 정수배가 아니라
픽셀이 뭉개진다. 크롬 쪽에서 작은 글자가 필요하면 크기 대신 `tone="muted"` 로 누른다.

### 3. 값은 관문을 지난다

`NaN` · `undefined` · `null` · `Infinity` · `[object Object]` 는 어떤 상태에서도 화면에 못 나간다.
`<Num>` · `<Word>` · `<Lines>` 가 `lib/cell.ts` 를 부르는 컴포넌트다 —
화면에서 부르는 것을 잊을 수 없게, 값을 그대로 꽂는 쪽이 **오히려 더 손이 가게** 만들었다.

`조각/값 관문` 스토리가 일부러 빈 값을 꽂는다. 대시(—)가 아닌 것이 하나라도 보이면 그것이 사고다.

## 색을 고를 때

1. 채움 위 글자는 `var(--bg)`, 판 위 글자는 `var(--fg)`. `#fff` 와 `var(--surface)` 를
   글자색으로 쓰지 않는다 — 둘 다 다크에서 어두워져 뒤집힌다.
2. 글자색을 바꿀 때는 바탕도 같이 본다. 단축 `background` 는 뒤에 오면 앞의 `background-image` 를 지운다.
3. 테마를 안 타고 늘 어두운 판(검색식 콘솔 · 홈 히어로)은 `--plate` 한 벌로.
4. 게임 원작 타입색(`--t-*`)은 바꾸지 않는다.

왼쪽 위 **테마 버튼**으로 라이트·다크를 갈아 끼운다. 조각을 만드는 동안 두 벌을 다 보는 것이
`scripts/check_contrast.mjs`(배포 전 42장)보다 앞선 그물이다 — 그쪽은 이미 난 사고를 잡는다.

## 돌리는 법

```bash
cd frontend-v4
npm run storybook          # :6006
npm run build-storybook    # storybook-static/ (배포물이 아니라 도면이다)
npm test                   # 관문 · 토큰 · 데이터 전량
```
